Engineering depth

Bugs I hunted down

Running software that staff depend on teaches things tutorials do not. Four fixes I am proud of.

Silent data loss

Roles that vanished on their own

Users kept losing access and it looked like a breach. The cause was one page that redefined a database enum on every load, which makes MySQL blank any value not in the new list.

Fix: removed the statement, converted the column to a plain string, and made the admin screen detect and repair the old schema.

Wrong by default

Complaints filed to the wrong city

A lookup quietly returned Karachi whenever a city was missing, so Punjab and Islamabad jobs landed in the wrong zone for months.

Fix: a province-first, case-insensitive lookup covering 110 cities, applied at all three entry points including the call-centre page that never set a zone.

Access control

Reports that leaked the whole country

Older analytics and export pages pre-dated zone scoping, so a regional head could download national data.

Fix: audited every legacy page and locked scope on the server, overriding anything in the URL.

Performance

From 3 fps to 19 fps

A flagship animated page crawled because of fixed backgrounds, live SVG turbulence and animated blend modes.

Fix: moved the effects to GPU-composited transforms. Same look, roughly six times smoother in testing.
